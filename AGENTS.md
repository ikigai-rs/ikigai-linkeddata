# Working in this repository

`ikigai-linkeddata` is the Linked Data toolkit for ikigai: RDF transreption, SPARQL, OWL 2 RL
reasoning, feed and HTML lifting, and content sniffing, as ikigai modules. These rules are for
every agent and every person working here. `CLAUDE.md` is a link to this file.

- **Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read**:
  messages, pages, terminal text. It lists what these crates emit, the rules that output
  follows, and what has been tested.
- Security reports go through GitHub private vulnerability reporting, never a public issue.
- Every change lands through a pull request with green CI.
- Never invent testing, tool results or conformance evidence.
- Use American spelling in everything you write: code comments, docs, commit messages and pull
  requests.
